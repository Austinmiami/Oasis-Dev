# Oasis Dev Portfolio

This repository contains a professional software engineering portfolio website for Austin (`Oasis Dev`). It showcases GitHub projects, skills, and contact information in a clean, modern layout.

## Files

- `index.html` — The main portfolio homepage.
- `style.css` — The stylesheet that controls the portfolio layout and visual design.
- `Document1/resume.pdf` — Resume file linked from the homepage (if present).
- `images/` — Image assets used by the portfolio.

## Features

- Hero section introducing the candidate and core expertise.
- Projects section with real GitHub repositories.
- Skills and about sections for hiring manager visibility.
- Contact section with email and GitHub/LinkedIn links.
- Responsive navigation and polished UI styling.

## Usage

1. Open `index.html` in a web browser to preview the portfolio.
2. Update the resume link, social links, and GitHub project URLs as needed.
3. Edit `style.css` to customize colors or layout.

## Customize

- Change the page title, description, and social metadata in `index.html`.
- Replace project summaries and tech stack entries with your latest work.
- Add project images in `images/` and update the markup if you want real thumbnails.

## Notes

This portfolio uses a simple static HTML/CSS structure so it can be hosted easily on GitHub Pages or any static site host.
